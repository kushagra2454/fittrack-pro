# ⚡ FitTrack - Personal Fitness Dashboard

Train Smarter. Track Better. Become Stronger.

FitTrack is a premier personal fitness tracking web application built with modern web technologies, responsive layouts, and interactive telemetry charts.

---

## 🚀 Features

- **Workout Tracker**: Real-time logging of exercises, sets, reps, and weights.
- **Nutrition & Calorie Counter**: Daily calorie goals, macronutrient splits, and progress rings.
- **Hydration Tracker**: Interactive water intake logging.
- **Strength PRs & Analytics**: Performance charts visualizing volume, weight progression, and consistency streaks.
- **Mobile Responsive**: Fully optimized for desktop, tablet, and mobile browsers.

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla CSS3** (Custom design system, CSS variables, dark mode aesthetics)
- **Vanilla JavaScript** (Modular ES6 architecture)
- **Chart.js** (Dynamic fitness analytics)
- **Netlify & GitHub Pages** (Static site hosting)

---

## 🌐 Deployment

This site is automatically deployed to Netlify via continuous deployment from GitHub.
